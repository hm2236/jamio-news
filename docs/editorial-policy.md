# 早さに、確かさを添えて。

JAMIO NEWSは、じゃみおのための個人ニュースサイトです。AI・PC・鹿児島の動きを、毎日の「じゃみお朝刊」に蓄積します。開設号は読み方のガイドであり、最新ニュースではありません。

## 3つの確認状態

- **確認済み事実**：公式発表、論文、GitHub、企業ブログなどの一次資料で、記事の主張を確認したもの。
- **報道**：信頼できる報道機関が伝えている情報。一次資料が未確認の点は明示します。
- **未確認情報**：Xなどで見つけた主張・速報。裏取りが終わっていない段階で、事実として断定しません。

確認状態は記事単位の要約です。異なる状態の主張を混在させるときは、本文でも主張ごとの状態を明示します。観測できた事実、投稿者の主張、編集部の考察を分けて書きます。

## Xは重要な発見の入口

研究者、開発者、最先端利用者、企業公式アカウントの投稿を拾います。企業公式でも、投稿だけで製品仕様や性能を確定させません。原典の発表・論文・リポジトリ・ブログを確認し、必要に応じて複数の信頼できる報道を照合します。

投稿のURL、投稿者、投稿時刻、閲覧・確認時刻、具体的な主張、裏取り先を残します。認証マークだけで本人性を判断せず、公式サイトからのリンクや所属情報も確認します。ベンチマークはモデル、ハードウェア、量子化、設定、比較条件を確認します。単一利用者の体験談を一般的な性能として扱いません。

Xにアクセスできない、投稿が削除された、ログインや利用条件で閲覧できない場合は取得不可と記録します。閲覧制限を回避せず、公式サイトや論文、GitHubなどで補います。Xを収集したふりはしません。投稿全文の転載を避け、短い要約と原典リンクで届けます。

## 重点テーマ

OpenAI、Anthropic、Google / Gemini、NVIDIA、AMD、Intel、ローカルLLM、AIコーディング、自動実装を重点化します。GPU・CPU・NPU、RAM・SSD、AI PC・ミニPC、Strix Halo、GB10 / DGX Spark / RTX Sparkでは、価格、メモリ、消費電力、ローカルLLM適性まで確認します。

鹿児島・いちき串木野は自治体・気象庁などの一次情報を優先。経済・生活欄では、暮らしへの具体的な影響を簡潔に示します。

## 価格ウォッチ

相場から約10％以上の変動、観測範囲で過去安値級、数千〜数万円の実質値引き、在庫復活、大幅な値上がりを重視します。「○％OFF」表示だけで安いと判定しません。

同じSKU・容量・店舗・購入条件で、税込・送料込みの支払額を比較します。クーポン、会員限定、ポイント、還元条件は分けて記録。獲得ポイントを無条件に現金値引きとみなしません。

**買い / 条件付きで買い / 様子見**は編集部の判断です。理由、観測時刻、販売店リンクを添えます。価格履歴の最安値は当サイトの観測範囲であり、市場全体の最安値ではありません。比較データが足りなければ判定を保留します。

## 天気と掲載日時

トップの天気は閲覧時にOpen-Meteoから取得するいちき串木野付近のモデル予報です。日付が今日と一致しない予報は表示せず、取得失敗はそのまま表示します。警報・注意報などの防災情報は気象庁で確認してください。記事・朝刊・価格の日時は日本時間です。

## 訂正と出典

記事には出典と確認時刻、Xを含む記事には検証メモを記載します。確認状態が変わった場合は記事を更新し、更新時刻と訂正履歴を残します。未確認から確認済みに変える際は、何がどの資料で確認できたかを明記します。

## 毎朝の配信について

朝8時の情報収集・朝刊生成・GitHub反映・チャット配信は将来の運用です。現在はMarkdownを追加して公開する仕組みを用意した段階です。収集・生成やチャット通知を自動実行する設定は有効化していません。
