# 早さに、確かさを添えて。

JAMIO NEWSは、じゃみおのための個人ニュースサイトです。AI・PC・VR/VRC・鹿児島の動きを、毎日の「じゃみお朝刊」に蓄積します。開設号は読み方のガイドであり、最新ニュースではありません。

## 3つの確認状態

- **確認済み事実**：公式発表、論文、GitHub、企業ブログなどの一次資料で、記事の主張を確認したもの。
- **報道**：信頼できる報道機関が伝えている情報。一次資料が未確認の点は明示します。
- **未確認情報**：Xなどで見つけた主張・速報。裏取りが終わっていない段階で、事実として断定しません。

確認状態は記事単位の要約です。異なる状態の主張を混在させるときは、本文でも主張ごとの状態を明示します。観測できた事実、投稿者の主張、編集部の考察を分けて書きます。

## Xは重要な発見の入口

研究者、開発者、最先端利用者、企業公式アカウントの投稿を拾います。企業公式でも、投稿だけで製品仕様や性能を確定させません。原典の発表・論文・リポジトリ・ブログを確認し、必要に応じて複数の信頼できる報道を照合します。

投稿のURL、投稿者、投稿時刻、閲覧・確認時刻、具体的な主張、裏取り先を残します。認証マークだけで本人性を判断せず、公式サイトからのリンクや所属情報も確認します。ベンチマークはモデル、ハードウェア、量子化、設定、比較条件を確認します。単一利用者の体験談を一般的な性能として扱いません。

Xにアクセスできない、投稿が削除された、ログインや利用条件で閲覧できない場合は取得不可と記録します。閲覧制限を回避せず、公式サイトや論文、GitHubなどで補います。Xを収集したふりはしません。投稿全文の転載を避け、短い要約と原典リンクで届けます。

## 重点テーマ

OpenAI、Anthropic、Google / Gemini、NVIDIA、AMD、Intel、ローカルLLM、AIコーディング、自動実装を重点化します。GPU・CPU・NPU、RAM・SSD、AI PC・ミニPC、Strix Halo、GB10 / DGX Spark / RTX Sparkでは、価格、メモリ、消費電力、ローカルLLM適性まで確認します。

鹿児島・いちき串木野は自治体・気象庁などの一次情報を優先。経済・生活欄では、暮らしへの具体的な影響を簡潔に示します。

## VR機器・VRChat（VRC）

VR機器・VRChat（VRC）を正式な追跡トピックとします。Meta Quest系・PC VR、SteamVR / OpenXR、Valve・Meta・HTC・PICO・Bigscreenの機器を対象に、アイトラッキング・フェイストラッキング・ハンドトラッキング・フルボディトラッキング（フルトラ）、無線化、GPU要件、価格・在庫を確認します。

VRChat本体のアップデート、SDK、Creator Economy、Trust & Safety、アバター / ワールド制作、イベント・コミュニティへの影響まで追います。公式リリースノート・開発者ドキュメント・告知を優先し、提供済み機能、ベータ版、将来計画を区別します。

新製品の発表だけで終わらず、今のVR環境から買い替える価値、必要スペックの変化、VRC体験への実際の効果、日本での価格・発売時期・入手性まで確認します。対応機器・ソフトウェア・接続方法・測定条件を添え、体験談と確認済み仕様、編集部の購入判断を分けます。

## 価格ウォッチ

相場から約10％以上の変動、観測範囲で過去安値級、数千〜数万円の実質値引き、在庫復活、大幅な値上がりを重視します。「○％OFF」表示だけで安いと判定しません。

同じSKU・容量・店舗・購入条件で、税込・送料込みの支払額を比較します。クーポン、会員限定、ポイント、還元条件は分けて記録。獲得ポイントを無条件に現金値引きとみなしません。

**買い / 条件付きで買い / 様子見**は編集部の判断です。理由、観測時刻、販売店リンクを添えます。価格履歴の最安値は当サイトの観測範囲であり、市場全体の最安値ではありません。比較データが足りなければ判定を保留します。

## 天気と掲載日時

トップの天気は朝刊・夕刊共通の情報です。ブラウザの位置情報利用を許可して現在地と地名を取得できた場合、都道府県・市区町村などの地名とOpen-Meteoのモデル予報を表示します。許可待ち・拒否・未対応・位置情報取得失敗・地名取得失敗・現在地の天気取得失敗時は「鹿児島県いちき串木野市」の地名と予報を表示し、理由を明示します。既定地点の天気も取得できなければ同じ地名のまま取得不可と表示します。日付は地点の現地時間で今日と照合し、古い予報は表示しません。防災情報は気象庁などで確認してください。記事・価格の日時と予報の取得時刻は日本時間です。

位置情報は天気と地名の表示のためだけに使います。小数点以下2桁に丸めた概略座標をOpen-Meteoへ、地名取得のためブラウザが取得した座標を[BigDataCloudの無料クライアント用API](https://www.bigdatacloud.com/free-api/free-reverse-geocode-to-city-api)へ、ブラウザから直接送信します。地名は日本語の都道府県・市区町村を優先します。許可を得た現在地のみを逆ジオコーディングし、既定地点の逆ジオコーディングやIPによる代替測位は行いません。当サイトのサーバー・リポジトリ・ログ・ブラウザストレージには保存せず、画面やページURLにも座標を表示しません。外部APIには通信元IPも伝わります。BigDataCloudは匿名化した座標とIPの組をサービス精度改善に利用すると説明しています。外部APIの取扱いは[Open-Meteoのプライバシーポリシー](https://open-meteo.com/en/privacy)と[BigDataCloudの説明](https://www.bigdatacloud.com/docs/article/why-is-reverse-geocoding-api-free)を参照してください。新規の有料API・秘密鍵・依存パッケージは不要です。 位置情報の許可はブラウザ設定から取り消せます。

## 訂正と出典

記事には出典と確認時刻、Xを含む記事には検証メモを記載します。確認状態が変わった場合は記事を更新し、更新時刻と訂正履歴を残します。未確認から確認済みに変える際は、何がどの資料で確認できたかを明記します。

## 毎朝の配信について

毎日06:00 JSTにChatGPT予定タスクが制作を始め、07:00 JSTまでの公開を目指す運用です。GitHubには日刊PRの検証・ビルド・公開を用意しています。取得不可や検証失敗を隠さず、期限を理由に出典確認を省略しません。このリポジトリ自体は調査・生成やチャット通知を自動実行しません。

## 朝刊と必要時の夕刊

朝刊はその日の土台を5本の主要記事で届けます。17:00 JSTの夕刊チェックでは、朝刊以降の重要更新を評価し、発行するか見送るかを編集判断します。影響範囲、意思決定への影響、技術・市場の転換点、緊急性、既報を覆す新規性、一次情報の強さ、じゃみおの関心との近さを総合します。

小ネタ1〜2本だけなら見送り、中程度のニュースが複数、または大きなニュースが1本でもあれば夕刊の対象です。噂・リークだけでは原則として大ニュースと扱いません。夕刊は確認できた重要記事1〜5本の可変長で、朝刊と同じ本数に揃えず、未閲覧の出典や埋め草を使いません。重要更新がなければ夕刊を作成せず、朝刊を最新号として残します。朝刊・昼刊・旧形式号の主要記事5本の契約は変えません。

トップの一面・トップニュースは最新号を基準にし、同日の朝夕の主要記事は「今日の重要ニュース」から残します。天気はトップ共通の閲覧時情報として扱い、記事本文やpublication digestに混ぜません。朝夕の切替で位置情報を再要求しません。夕刊も出典、Xの取得状況、時系列、CI、正確なmain SHAの公開receiptを同じ基準で検証します。この方針の追加自体は予定タスクの新規登録や変更を行いません。
